# Runware

> Runware is a unified AI inference platform — "one API for all AI" — exposing a single task-based endpoint for image, video, audio, 3D, and text (LLM) generation across 400K+ open and closed-source models. Requests are task objects (taskType, taskUUID, model identifier, parameters) posted over HTTP, WebSocket, or Server-Sent Events. Models are addressed as creator:family@version and billed pay-per-request. Official TypeScript and Python SDKs, a CLI, a hosted MCP server, and Agent Skills reach the same surface.

## APIs

- [Runware Inference API](https://runware.ai/docs/platform/introduction): Single endpoint (https://api.runware.ai/v1) for image, video, audio, 3D, and text inference. Auth via API key.
